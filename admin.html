Sign in

Saving here commits to the website repo and publishes the live site. That needs a GitHub token with write access.

How to make the token (once)
  1. Sign in to GitHub as joshbaker624, then open Settings → Developer settings → Fine-grained tokens.
  2. Name it CBMF sponsor manager and set an expiry — a year is fine, you will just make a new one.
  3. Repository access: Only select repositories → cbmf-website. Not “all repositories”.
  4. Permissions: Contents → Read and write. Nothing else is needed.
  5. Generate, copy, and paste it above. It is stored in this browser only — never in the website files.

That scope means the worst a stolen token can do is edit this one website repo — not your account, and not your other repos.
